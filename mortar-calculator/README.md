# Mortar Calculator

A static target distance calculator for L-81 mortar and artillery range checks.

## Features

- Accepts labeled coordinates such as `x98.43, y110.38`, `X: 98.43 Y: 110.38`, and two plain numbers.
- Updates the distance and range status as coordinates are entered.
- Stores up to eight recent calculations locally on the current device.
- Copies shareable links containing the current coordinates.
- Restores coordinates from shared links.
- Supports system, light, dark, ocean, Night Ops, Desert Ops, and WarDogs themes.

Open `index.html` directly or serve this folder with any static web server.
